# Alignment Academy

Alignment Academy is the training and certification arm of the Aligned4Life Project.

## Local Development

```bash
npm install
npm run dev -- -p 4000
```

Open [http://localhost:4000](http://localhost:4000).

## Pages

- Home
- About the Academy
- The Program
- Transformational Coaching
- Certification
- Join / Contact

## Build

```bash
npm run build
```

## Hostinger Node.js Deployment

Use the repository's `main` branch with these commands:

```bash
npm install
npm run build
npm start
```

This is a Next.js Node.js application. Deploy it as a Node.js app, not as a static site. The `start` script uses Hostinger's assigned `PORT` environment variable automatically.
